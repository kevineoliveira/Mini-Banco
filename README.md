## Mini-Banco

Um projeto criado no curso Assistente de Desenvolvimento de Aplicativos Computacionais na unidade Senac São Carlos, a ideia principal vai ser seguir a mesma estrutura de um banco, contendo saques, depósitos, impressões de extratos, exibições de saldos, entre outros.
Funcionalidades

- Sacar.
- Depositar.
- Exibir extrato.
- Ver saldo atual.

## Tecnologias Utilizadas

- Linguagem de Programação Java.

## Tecnologias de Apoio

- Vs Code.
- Biblioteca Scanner.
